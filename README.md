# ORCA

ORCA 社内ポータルの新デザイン（静的モック）。AI 回答機能は含まない。

## 開き方

ビルド不要。リポジトリ直下で静的サーバーを立ててブラウザで開く。

```sh
python3 -m http.server 8000
# http://localhost:8000/
```

設定の「ホーム」で、ホームのクイックアクセス4枠を好きな機能に入れ替えられる。オンハンドは既定ではオフ。施設を選ぶとホームに表示され、施設の切り替え（複数選ぶと ALL で合算）、1か月 / 3か月の切り替え、ADR・OCC・RevPAR の予算 / 現在（予測）/ 予算比 / 前年比、日別グラフ（実績は実線・今日以降は点線、前年・予算の重ね表示、ドラッグか左右キーで日付を移動、月の切り替え）が使える。

各ページ左上の「戻る」は直前のページへ戻る。URL を直接開いた場合は親の一覧（Agents / Library）へ戻る。

## ファイル

- `core.js` — アイコン、保存、サンプルデータ生成、グラフ描画
- `features.js` — 機能の一覧とニュース
- `tools.js` — TODO・競合調査・パリティ判定・AI Weekly・口コミ
- `tools2.js` — BC画像検索・オペマニュアル・RM・ダッシュボード・夜タスク
- `onhand.js` — ホームのオンハンド表示（設定で施設と最初に開く指標を選ぶ）
- `loader.js` — チャット送信後の「考えています」アニメーション（シャチがリングをくぐる。素材は `assets/loader/`）
- `settings.js` — 設定ダイアログ
- `app.js` — ナビゲーション、ホーム、チャット、一覧、ルーター

## ロゴ素材

- `assets/orca-wordmark.svg` — 支給ワードマークをベクターで描き直したもの（`currentColor` で着色、CSS ではマスクとして使用）
- `assets/orca-mark.webp` / `orca-mark.png` — 支給マーク（4096px PNG）を余白トリムして縮小
- `assets/orca-orb-soft.webp` — ヒーロー背景用にマークの暗部を淡いブルーへ寄せた版
- `assets/orca-mark-{32,64,180}.png` — favicon / apple-touch-icon

## 動きの設定

シャチのローディングやコネクタの回転は、既定で常に動く。止めたい人は 設定 → 個人設定 →「動きを減らす」をオンにする（端末の「視差効果を減らす」には連動しない）。

## テーマ

設定 → 個人設定 → テーマで、ライト / ダーク / **FHG** / 自動を選べる。FHG は黒に FHG のブランドカラー（`#dd5234`）を混ぜた配色で、ORCA の青いマークやシャチも朱色寄りに色味を回している（`styles.css` の `:root[data-theme="fhg"]`）。
